# UI 重构实施基线

本轮只调整展示层，不修改 `ProductController`、Training Bridge v1、训练结果状态语义和隐私边界。底部导航保留“首页 / 计划 / 饮食 / 记录 / 教练”五个入口。动作图片资产与 `exerciseId` 映射暂缓，当前继续使用统一图标占位。

## 页面状态矩阵

| 页面 | 默认 | 加载 | 空数据 | 错误 | 禁用 / 降级 |
| --- | --- | --- | --- | --- | --- |
| App Shell | 五栏导航和全局刷新 | 品牌加载态 | 首次进入档案页 | 刷新错误以低干扰提示展示 | 本地模板继续可用 |
| 首页 | 问候、今日训练、周进度、饮食 | 刷新状态 | 无计划时显示恢复卡 | Agent 错误显示来源说明 | 身体不适时移除训练 CTA |
| 计划 | 阶段、来源、今日安排 | 主 CTA 显示打开中 | 无动作时显示恢复日 | 服务错误后显示本地模板 | 训练启动期间 CTA 禁用 |
| 饮食 | 今日一般建议与边界 | 随全局刷新 | 无远端结果时使用本地模板 | 来源徽标明确降级 | 不提供热量或医疗推断 |
| 记录 | 统计、AI 周报、训练列表 | 周报生成中 | 无历史时显示空状态 | 周报失败可重试 | 未授权时不显示 AI 周报 |
| 训练总结 | 状态、次数、目标进度、反馈 | Agent 总结生成中 | 没有总结时显示说明 | 总结失败提供重试 | cancelled / interrupted 不计完成 |
| AI 私教 | 记忆摘要、聊天、输入框 | 记忆加载 / 消息发送 | 无消息时显示建议问题 | 错误保留输入和重试语义 | 未授权时显示隐私启用说明 |
| 个人档案 | 目标、基础、频率、时长、条件 | 保存中 | 不适用 | 保存失败 Snackbar | 保存中禁用操作 |
| Agent 设置 | 服务、授权、数据管理 | 检测 / 保存中 | 未配置时显示本地模式 | 连接失败显示错误状态 | 忙碌时禁用表单与按钮 |

## 视觉规则

- 8pt 间距体系，页面水平边距 16px，模块间距 12–20px。
- 主页面使用白色和暖灰底，高饱和深色仅用于首页训练 Hero 和关键状态。
- 卡片 16px 圆角，控件 12px 圆角，标签使用胶囊圆角。
- 绿色用于训练和完成，紫色用于 AI，琥珀色用于模板/模拟/提示，珊瑚色仅用于错误。
- 所有主要点击目标至少 44px；360px 宽度下避免固定宽度文字区。
