# AI 健身教练产品功能介绍视频录制指南

> 适用项目：`app/ai_fitness_coach`
> 推荐成片时长：4～5 分钟
> 推荐画面：手机竖屏录屏为主，真人训练侧拍为辅
> 核心叙事：训练前个性化建议 → 训练中端侧识别纠错 → 训练后总结沉淀 → AI 私教持续陪伴

## 一、视频要讲清楚什么

视频不应只是依次点击页面，而要回答四个问题：

1. 用户为什么需要它：独自训练时缺少计划、动作反馈和长期陪伴。
2. 产品怎么解决：根据用户画像生成建议，用手机摄像头进行端侧动作识别，再由 AI 私教结合训练记录提供连续建议。
3. 产品的核心亮点是什么：动作计数与纠错、训练闭环、聊天记忆、隐私可控。
4. 用户最终获得什么：更清晰的计划、更及时的动作反馈，以及能够记住训练情况的长期私教。

建议将产品定位概括为：

> 一款兼顾端侧动作识别、个性化训练建议和长期记忆的 AI 健身私教。

## 二、录制前必须完成的准备

### 1. 准备可稳定演示的版本

- 安装最新 Debug APK，并确认首页、训练、历史、AI 私教均能打开。
- 正式录制前至少完整走一遍：画像 → 训练 → 总结 → 历史 → AI 对话 → 查看记忆。
- Agent 服务应在整段录制期间保持在线，优先使用稳定的 HTTPS 地址。
- 如果使用临时 HTTPS 隧道，录制期间不要关闭 Agent、终端或隧道进程；开拍前重新检测一次连接。
- DeepSeek 等模型 API Key 只放在 Agent 服务端，不能出现在 APP 输入框、录屏、终端或成片中。
- “开发访问凭据”和 HTTPS 地址提前配置完成。最终成片不要展示凭据；必须展示设置页时，应在剪辑中打码。

### 2. 准备演示数据

建议使用一套统一、容易理解的测试画像：

- 目标：增肌或提升体能；
- 每周训练：3 次；
- 单次时长：30 分钟；
- 训练偏好：居家、无器械；
- 当前身体不适：无。

提前生成或完成以下数据：

- 至少 2 条历史训练记录；
- 一条包含标准动作的训练记录；
- 一条包含常见动作问题的训练记录；
- 一段已成功保存的 AI 私教对话；
- Agent 记忆中已有画像、训练记录或聊天内容。

不要让演示账号堆积大量无关测试数据。日期、训练次数和计划内容应彼此合理，避免出现“今天尚未训练”却已有当天完成记录等穿帮情况。

### 3. 准备拍摄环境

- 手机电量保持在 60% 以上，关闭省电模式。
- 开启“勿扰模式”，关闭微信、短信、来电和系统更新通知。
- 清理通知栏中的个人信息。
- 字体大小、显示缩放保持系统默认，避免文字截断。
- 使用干净、光线均匀的背景，训练者与背景颜色要有明显反差。
- 深蹲和俯卧撑均尽量采用侧面机位，保证肩、髋、膝、踝完整入镜。
- 手机固定在三脚架上，镜头与身体中部大致同高；不要手持拍训练识别画面。

### 4. 推荐录制参数

- 手机录屏：1080p、30 fps、竖屏、关闭触摸轨迹显示。
- 真人侧拍：1080p、30 fps；光线充足时可使用 60 fps。
- 后期成片：1920×1080 横屏。
- 横屏画布中可将竖屏 APP 画面放在左侧，右侧放标题、真人侧拍或功能说明。
- 旁白单独录制，环境音仅在动作识别段适当保留。

建议同时准备两台设备：演示手机负责运行 APP 和录屏，另一台手机负责拍摄训练者与手机摆放关系。后期将两路画面同步。

## 四、建议直接使用的操作脚本

### 镜头 1：开场

画面：快速展示首页、摄像头骨架、训练总结和 AI 对话，每个画面停留 2～3 秒。

字幕建议：

- “看得懂动作”
- “记得住训练”
- “给得出建议”

开场不要先录登录、授权或服务配置，这些步骤节奏慢，也不能第一时间体现产品价值。

### 镜头 2：用户画像与个性化首页

操作顺序：

1. 从首页进入画像编辑。
2. 缓慢滑动，展示训练目标、频率、时长和偏好。
3. 保存后回到首页。
4. 依次点开今日计划和饮食建议。

录制要点：每次点击后停留约 2 秒，让观众看清页面层级；不要快速来回滑动。

### 镜头 3：动作识别与纠错

操作顺序：

1. 首页点击“自由训练”。
2. 选择“徒手深蹲”。
3. 将手机固定在身体侧面，确保全身入镜。
4. 保持起始站姿约 1 秒，再开始动作。
5. 完成 3 次标准深蹲。
6. 第 4 次故意幅度不足或躯干明显前倾，用于展示纠错提示。
7. 再完成 1 次标准动作并结束训练。

如果要展示俯卧撑，建议单独补拍，不要在同一训练会话中切换动作。俯卧撑需保证肩、髋、踝均在画面内，避免衣服与地面颜色过近。

重要说明：当前功能属于基础姿态识别和动作提示，不应在旁白中描述为“医疗诊断”“零误差识别”或“保证避免运动损伤”。

### 镜头 4：训练总结与历史

操作顺序：

1. 点击完成训练。
2. 展示目标次数、实际次数、训练时长和主要动作问题。
3. 等待 AI 私教总结生成完成后再录屏。
4. 返回历史页，确认本次训练已经出现。
5. 打开本周回顾或历史详情。

为了避免等待模型生成破坏视频节奏，可以先完整训练一次并确认总结可用，再正式录制；成片中保留短暂加载动画即可，建议不超过 2 秒。

### 镜头 5：AI 私教聊天与记忆

推荐第一轮提问：

> 根据我最近的深蹲训练表现，下一次训练最应该注意什么？

理想画面：回答中能够引用最近训练次数、动作问题或当前计划，而不是只给通用建议。

推荐第二轮提问：

> 请记住我更喜欢居家无器械训练，每周计划训练三次。

随后退出 AI 私教页面再重新进入，提问：

> 结合我的偏好，给我一句下一次训练建议。

最后打开“Agent 记忆”，展示：

- 用户画像或偏好；
- 最近训练事实；
- 最近聊天内容；
- “删除全部 Agent 聊天与记忆”按钮。

不建议在正式视频中真的点击最终删除确认，否则后续补拍可能失去演示数据。可以停留在确认弹窗后取消。

### 镜头 6：隐私设计

画面可以使用产品页与后期图示组合，不必进入开发配置页。

建议图示：

```text
摄像头画面
    ↓ 仅在手机端处理
MediaPipe 姿态识别与动作分析
    ↓ 上传有限的结构化训练事实（需用户授权）
AI 私教建议与有限记忆
```

旁白应准确表述为：

> 摄像头视频、图片和逐帧关键点不进入云端请求；只有在用户明确授权后，有限的画像字段和结构化训练记录才会用于 AI 私教服务。

不要笼统宣称“所有数据永不上传”，因为聊天、授权后的画像字段和结构化训练事实需要发送给 Agent。

## 五、推荐的拍摄与剪辑方式

### 方案 A：最稳妥的双机位方案

1. 演示手机开启系统录屏，只录 APP 界面。
2. 第二台手机横屏拍摄训练者和演示手机。
3. 动作开始前拍一下手掌或拍手，用于两路素材对齐。
4. 后期将 APP 录屏放大显示，动作识别部分切为左右分屏。
5. 旁白最后统一录制，避免边操作边说造成卡顿。

这是最推荐的方式，因为既能看清识别界面，又能证明系统正在识别真人动作。

### 方案 B：时间紧张的一镜到底方案

按以下路线连续操作：

```text
首页 → 画像 → 今日计划 → 自由训练 → 深蹲 → 训练总结
     → 历史记录 → AI 私教 → Agent 记忆 → 首页收尾
```

一镜到底应控制在 5 分钟以内。出现网络等待时不要反复点击按钮，可停顿后在后期剪掉等待段。

## 六、字幕和视觉包装建议

- 统一使用一种中文无衬线字体，标题和正文字重有所区分。
- 字幕放在安全区域内，不遮挡 APP 底部导航和主要按钮。
- 每个功能段只保留一个核心标题，例如“端侧识别”“训练闭环”“长期记忆”“隐私可控”。
- 技术名词第一次出现时用简短解释，例如“MediaPipe：端侧人体姿态识别”。
- 重要数据可用轻量放大或描边强调，不要添加过多炫光、粒子和快速转场。
- 触摸操作尽量使用后期圆点或轻微缩放提示，避免使用系统开发者选项中的持续触摸轨迹。
- APP 为竖屏时，横屏画布空余区域可以放真人画面、流程图或一句功能说明，不要简单拉伸界面。

## 七、不能入镜或必须打码的内容

- DeepSeek 或其他模型的 API Key；
- 开发访问凭据；
- Agent 服务端环境变量和配置文件；
- 终端命令历史中的密钥；
- 真实姓名、手机号、通知消息和聊天账号；
- 与比赛无关的测试数据；
- 临时隧道管理页面、内部 IP、调试日志和报错堆栈。

如果必须展示“Agent 连接”页面，只展示以下信息：

- 服务使用 HTTPS；
- 连接检测成功；
- 用户可以自主开启或关闭数据授权。

凭据输入框和完整服务地址应打码或裁掉。

## 八、避免过度宣传

当前演示可以明确展示：

- 深蹲与俯卧撑的端侧姿态识别；
- 基础动作计数、阶段判断和纠错；
- 画像、训练计划、饮食建议、历史和总结；
- AI 私教聊天、有限记忆查看与删除；
- 原始训练记录优先本地保存；
- 用户授权与服务不可用时的回退设计。

不要声称：

- 已替代专业教练或医生；
- 能诊断伤病或提供医疗处方；
- 所有动作、机位和人群均能百分之百识别；
- 视频上传云端进行实时分析；
- AI 建议永远正确；
- 当前原型已经完成大规模运动医学验证。

推荐在片尾或说明文字中加入：

> 本产品提供一般性健身辅助，不替代医生、康复师或专业教练建议。身体不适时请停止训练并寻求专业帮助。

## 九、开拍前检查清单

### 产品检查

- [ ] 最新 APK 已安装，版本正确。
- [ ] HTTPS Agent 服务在线，连接检测成功。
- [ ] 模型服务能够正常生成回答。
- [ ] 用户已明确开启所需的数据授权。
- [ ] 首页计划和饮食内容正常。
- [ ] 深蹲与俯卧撑入口可用。
- [ ] 训练完成后能进入总结页并保存历史。
- [ ] AI 私教聊天、记忆查看功能正常。
- [ ] 演示账号已有干净、合理的测试数据。

### 拍摄检查

- [ ] 手机电量和存储空间充足。
- [ ] 勿扰模式已开启，通知栏已清理。
- [ ] 镜头、屏幕和训练场地干净。
- [ ] 人体全身能够稳定入镜。
- [ ] 录屏和外拍设备均为 1080p、30 fps。
- [ ] 已试录 10 秒并检查画面、声音和屏幕文字。
- [ ] 所有密钥、凭据和个人信息均不会入镜。

### 成片检查

- [ ] 前 20 秒已经出现核心价值或识别画面。
- [ ] 能看懂“训练前—训练中—训练后”的完整闭环。
- [ ] AI 回答确实引用了用户画像或训练事实。
- [ ] 隐私表述准确，没有“完全不上传”等错误宣传。
- [ ] 所有等待、误触、报错和无效操作已经剪掉。
- [ ] 片尾包含产品名称、团队信息和必要免责声明。

正式录制前建议先拍一版低成本样片，团队只检查三件事：故事是否顺、核心功能是否清楚、是否存在技术或隐私表述错误。确认后再补录高清素材和正式旁白。
